# WAL Arithmetic

Mobile-first practice app for operations on whole numbers, fractions, decimals, and integers.

## Now playable
Whole numbers → Addition →

1. Single-digit + single-digit
2. One-digit + two-digit
   - Ones sum less than 10
   - Carry 1 ten
   - Carry makes a new hundred

One active cell, four digit choices, stay until correct, then Next or Menu.
